# V19 — Iconos animados para Conoce los Corales

Basado en V18. Sustituye los iconos estáticos de las tarjetas por microanimaciones SVG ligeras y coherentes con el diseño:
- coral: ramas y partículas en movimiento suave
- animal: pulso del núcleo y pequeñas aletas
- arrecife: ondulación de agua y burbujas
- importancia: oscilación orgánica
- red ecológica: enlaces que se dibujan y nodos que pulsan
- datos para recordar: bombilla con brillo/rayos

Las animaciones respetan `prefers-reduced-motion`.
